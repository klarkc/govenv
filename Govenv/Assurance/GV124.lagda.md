# GV124 assurance

GV124 is observed at the Stage-0 environment boundary. The governed check
requires the shell to expose Agda 2.8.0 and the matching official Agda Language
Server v8; `devenv.nix` exercises the same observations in `govenv:check`.

The assurance models the required observation shape. The executable shell check
is the candidate-state witness and the counterexample demonstrates that a
missing or mismatched LSP cannot satisfy the rule.

```agda
{-# OPTIONS --safe #-}

module Govenv.Assurance.GV124 where

open import Agda.Builtin.Bool using (Bool; true; false)
open import Agda.Builtin.Equality using (_≡_; refl)
open import Agda.Builtin.List using (List; []; _∷_)
open import Agda.Builtin.String using (String; primStringEquality)
open import Govenv.Kernel.Assurance using
  (ObservedEvidence; observedEvidence)
open import Govenv.Kernel.Fact using
  (Facts; observed; empty; _∷ᶠ_)
open import Govenv.Kernel.Rule using (Rule)
open import Govenv.Kernel.Verdict using (Verdict; holds; violated)

data Subject : Set where
  agdaToolchain : Subject
  agdaLanguageServer : Subject

Observation : Subject → Set
Observation agdaToolchain = String
Observation agdaLanguageServer = String

dependencies : List Subject
dependencies = agdaToolchain ∷ agdaLanguageServer ∷ []

data Diagnostic : Set where
  incompatibleAgdaLanguageCapability : Diagnostic

data Obligation : Set where
  observeAgdaLanguageCapability : Obligation

_and_ : Bool → Bool → Bool
true and right = right
false and right = false

check : Facts Subject Observation dependencies →
  Verdict Diagnostic Obligation
check ((observed agdaVersion) ∷ᶠ ((observed alsVersion) ∷ᶠ empty))
  with primStringEquality agdaVersion "Agda version 2.8.0"
       and primStringEquality alsVersion "Agda v2.8.0 Language Server v8"
... | true = holds
... | false = violated incompatibleAgdaLanguageCapability

rule : Rule Subject Observation dependencies Diagnostic Obligation
rule = record { check = check }

evidence : ObservedEvidence 124
evidence =
  observedEvidence
    Subject Observation dependencies Diagnostic Obligation rule

canonicalFacts : Facts Subject Observation dependencies
canonicalFacts =
  (observed "Agda version 2.8.0") ∷ᶠ
  ((observed "Agda v2.8.0 Language Server v8") ∷ᶠ
  empty)

canonicalCapabilityAccepted :
  Rule.check rule canonicalFacts ≡ holds
canonicalCapabilityAccepted = refl
```
