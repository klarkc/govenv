# GV110 assurance

GV110 keeps Protocol judgment non-constitutional while making review freshness
explicitly checkable. The generic vigilance relation accepts exactly the
counter transitions described by Protocol, and the project-purpose snapshot is
derived from the canonical purpose plus its review index.

```agda
{-# OPTIONS --safe #-}

module Govenv.Assurance.GV110 where

open import Agda.Builtin.Bool using (true; false)
open import Agda.Builtin.Equality using (_≡_; refl)
open import Govenv.Kernel.Assurance using (StaticEvidence; staticEvidence)
open import Govenv.Kernel.ProjectPurpose using (projectPurposeSnapshot)
open import Govenv.Kernel.Protocol using (protocolVigilanceFresh)
open import Govenv.Materialization using (Materialization)
import Govenv.Materialization.ProjectPurposeSnapshot as PurposeSnapshot
open import Govenv.Project using
  (purpose; purposeReviewIndex)

record Proposition : Set where
  constructor satisfied
  field
    noTriggerPreserves :
      protocolVigilanceFresh false false 4 4 ≡ true
    noTriggerRejectsBump :
      protocolVigilanceFresh false false 4 5 ≡ false
    reaffirmationAdvancesOnce :
      protocolVigilanceFresh true false 4 5 ≡ true
    reaffirmationRejectsStale :
      protocolVigilanceFresh true false 4 4 ≡ false
    revisionResetsWithoutTrigger :
      protocolVigilanceFresh false true 4 0 ≡ true
    revisionResetsWithTrigger :
      protocolVigilanceFresh true true 4 0 ≡ true
    revisionRejectsNonzero :
      protocolVigilanceFresh true true 4 1 ≡ false
    purposeSnapshotIsCanonical :
      Materialization.state PurposeSnapshot.materialization ≡
        projectPurposeSnapshot purpose purposeReviewIndex

proof : Proposition
proof = satisfied refl refl refl refl refl refl refl refl

evidence : StaticEvidence 110
evidence = staticEvidence Proposition proof
```
