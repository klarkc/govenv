# GV127 assurance

GV127 records the result of the required reuse-first ecosystem investigation.
The compiler proves that the reviewed disposition is present and bound into
Govenv; it does not claim that an ecosystem search can be made mathematically
complete.

The investigation found useful reusable lint components, but no maintained
candidate that satisfies the formatter + linter + LSP boundary as a whole:

- Agda Language Server v8 exposes the language service used by GV126, but its
  advertised LSP capabilities do not include document or range formatting.
- `arghda-core` provides a current Agda workspace linter with seven checks,
  but no formatter or LSP formatting endpoint and documents `.agda` scanning.
- `agda-unused` 0.3.0 supports Agda 2.8.0 and provides reusable unused-code
  analysis with JSON output, but it is a linter rather than a formatter/LSP.
- Historical or narrow pretty-printer projects do not provide an adequate
  maintained drop-in formatter for both `.agda` and literate `.lagda.md`.

Therefore GV128 should reuse compatible lint functionality where it reduces
bespoke code, while supplying the missing formatting/LSP adapter boundary
inside Stage 0. GV129 owns the later complete stdlib-style inventory and 100%
coverage target.

module Govenv.Assurance.GV127 where

open import Agda.Builtin.Equality using (_≡_; refl)
open import Agda.Builtin.String using (String)
open import Govenv.Kernel.Assurance using (StaticEvidence; staticEvidence)

alsDisposition = "reuse-language-server-no-formatting"

arghdaDisposition = "reuse-lint-candidate-no-formatter-no-lsp-formatting"

  constructor satisfied
  field
    alsReviewed :
      alsDisposition ≡ "reuse-language-server-no-formatting"
    arghdaReviewed :
      arghdaDisposition ≡
        "reuse-lint-candidate-no-formatter-no-lsp-formatting"
    unusedReviewed :
      unusedDisposition ≡ "reuse-unused-analysis-candidate"
    formatterReviewed :
      formatterDisposition ≡ "no-adequate-maintained-drop-in-found"
    selectedBoundary :
      decision ≡
        "reuse-lint-components-and-provide-stage0-formatting-lsp-adapter"

proposition : Set
proposition = Proposition

evidence : StaticEvidence 127
evidence =
  staticEvidence proposition
    (satisfied refl refl refl refl refl)
