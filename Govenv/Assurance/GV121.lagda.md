# GV121 assurance

GV121 closes the candidate-boundary enforcement gap left by GV119. Candidate
classification remains a Protocol judgment, but the compiler decides whether
the recorded assessment, evidence, debt, and bypass permit the candidate.

```agda
{-# OPTIONS --safe #-}

module Govenv.Assurance.GV121 where

open import Agda.Builtin.Bool using (true; false)
open import Agda.Builtin.Equality using (_≡_; refl)
open import Agda.Builtin.List using ([]; _∷_)
open import Govenv.Kernel.Assurance using (StaticEvidence; staticEvidence)
open import Govenv.Kernel.Learning
open import Govenv.Learning using (candidateAllowed)

sampleDebt : LearningDebt
sampleDebt =
  learningRequirement
    "Explain the candidate learning boundary."
    "base-revision"
  ∷ []

record Proposition : Set where
  constructor satisfied
  field
    currentCorrectiveBootstrapIsAllowed :
      candidateAllowed ≡ true
    expandingCandidateRequiresRequirements :
      candidateLearningAllowed
        feature expands false true true [] noBypass ≡ false
    featureCannotCarryUnlearnedRequirements :
      candidateLearningAllowed
        feature expands true false true sampleDebt noBypass ≡ false
    correctiveBypassMayPreserveDebt :
      candidateLearningAllowed
        corrective expands true false true sampleDebt urgentCorrective ≡ true
    correctiveBypassCannotLoseDebt :
      candidateLearningAllowed
        corrective expands true false false sampleDebt urgentCorrective ≡ false

proof : Proposition
proof = satisfied refl refl refl refl refl

evidence : StaticEvidence 121
evidence = staticEvidence Proposition proof
```
